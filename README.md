# 🚗 小手开车车 · 手势驾驶小游戏 V2

**[立即在线试玩](https://xiangshu3721.github.io/hand-drive-game/)**

儿童 H5 汽车躲障碍小游戏。电脑、手机、iPad 打开网页即可玩，无账号、无广告、无后端。

## 操作

| 模式 | 左右转向 | 加速 | 减速 |
|---|---|---|---|
| 摄像头手势 | ✋ 手掌左右移动 | ✌️ 剪刀手（伸出食指和中指） | ✊ 握拳 |
| 手机/iPad触控 | 道路上手指左右滑动 | 按住右侧🚀 | 按住右侧🐢 |
| 电脑 | 鼠标拖动、A/D 或 ←/→ | W 或 ↑ | S 或 ↓ |

手势保持约 0.2 秒后生效，短暂失去手势时速度会恢复正常。**摄像头小窗不再展示**，但手势模式仍需要摄像头权限。首次识别要联网加载 MediaPipe Hands 模型。

## V3 三关挑战与 iPad 沉浸式全屏

- 第 1 关「轻松起步」：距离 0–320，路障主要为单个，下降速度从 175 逐步增加至 220 像素/秒，生成间隔从 1.80 秒缩短至 1.39 秒。
- 第 2 关「弯道挑战」：距离 320–790，下降速度 230–291，间隔 1.37–1.03 秒，双路障概率从 12% 增加至 38%。
- 第 3 关「闪电冲刺」：距离 790–1450，下降速度 305–382，间隔 1.08–0.80 秒，双路障概率从 33% 增至 58%。到达 1450 分自动通关。
- 三关自动衔接；进度条展示当前关卡完成比例；切关时短暂清除路障并给予保护，避免意外连撞。
- 双路障行最多占两条车道，至少留一条安全通道；双障碍的安全通道与上一行之间最多相邻移动。
- 这些速度是正常驾驶的基础下降速度；剪刀手/加速按钮使其乘 1.6，握拳/减速按钮使其乘 0.58，同时出障碍间隔相应调整。
- 页面现在铺满浏览器可用视口，iPad 横屏不再被限制在 520px 的竖屏游戏框；HUD/赛道/汽车与路障适配屏幕。⛶ 按钮尽可能调用浏览器全屏 API。
- **iPad Safari 顶部地址栏属于浏览器本身，网页 CSS 不能去除。**要进入更完整的沉浸式体验，Safari 中点「分享」→「添加到主屏幕」，之后从主屏幕图标打开游戏（已设置 Apple 独立 Web App 元信息）。

## 历史记录与累计星星

- 捡到星星立即保存到当前浏览器的 localStorage，中途离开也保留已获得星星。
- 三颗爱心耗尽后记录一次完整游戏：日期、操控模式、距离、当局星星；最近 80 局可浏览。
- 累计星星、完成游戏总局数、最高距离单独长期保存，不随重玩归零。
- 进入首页的「我的游戏记录」或结算页「查看历史记录」。
- 仅本机浏览器保存，换浏览器/换设备不互通；清理网站数据或无痕模式可能丢失。
- 升级前保存的最高分会自动保留；旧版并没有记录累计星星或历史局数，无法补算。

## 部署和维护

GitHub Pages 从仓库 `main` 分支根目录发布。根目录 `index.html` 内嵌 HTML、CSS、JavaScript，可直接部署，无构建和服务器需求。

手势依赖：MediaPipe Hands（Apache-2.0）。摄像头视频仅在当前设备进行姿态识别；应用不会上传视频。第三方 CDN 仅用于下载手势模型资源；国内网络可能无法稳定访问，后续可将模型资源自托管。
