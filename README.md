# 🚗 小手开车车 · 手势驾驶小游戏 V4

**[立即在线试玩](https://xiangshu3721.github.io/hand-drive-game/)**

儿童 H5 汽车躲障碍小游戏。电脑、手机、iPad 打开网页即可玩，无账号、无广告、无后端。

## 操作

| 模式 | 左右转向 | 加速 | 减速 |
|---|---|---|---|
| 摄像头手势 | ✋ 手掌左右移动 | ✌️ 剪刀手（伸出食指和中指） | ✊ 握拳 |
| 手机/iPad触控 | 道路上手指左右滑动 | 按住右侧🚀 | 按住右侧🐢 |
| 电脑 | 鼠标拖动、A/D 或 ←/→ | W 或 ↑ | S 或 ↓ |

手势保持约 0.2 秒后生效，短暂失去手势时速度会恢复正常。**摄像头小窗不再展示**，但手势模式仍需要摄像头权限。首次识别要联网加载 MediaPipe Hands 模型。

## V4 三档开局可选难度（无限模式）

开局先选择难度，再选择手势或触屏操控。每次游戏固定在当前难度，**不会自动切关，也没有里程终点**。三颗爱心用完才结算；点「再玩一次」仍使用相同难度，回首页可重新选难度。

| 难度 | 标准跑道滚动/路障下降速度 | 标准障碍行生成间隔 | 单行双路障概率 | 挑战强度指数 |
|---|---:|---:|---:|---:|
| 🌼 简单 | 180 px/s | 1.80s | 4% | 1× |
| 🔥 困难 | 300 px/s | 1.00s | 34% | 3× |
| ⚡ 超级难 | 450 px/s | 0.45s | 68% | 10× |

**强度指数** =（基础下降速度 / 180）×（1.8 / 生成间隔），因此严格对应 1 : 3 : 10 的**设计压力指标**，不是精确测量的玩家失败概率或人类难度倍数。障碍密度、速度、双路障数量三个维度都分档区分；每个模式内随存活时间缓慢再提高速度（最高 +16%）与刷障频率（最高 +12%），但不会自动跳到另一模式。路障最多占两条车道，至少保留一条安全通道。

加速和减速手势/按键继续生效（分别乘以 1.6 与 0.58），道路滚动速度与障碍下落速度同步变化。

### iPad 游戏框大小

- 从 V3 的整屏横向大赛道恢复为**最大约 730px 宽的居中游戏框**，比初版的 520px 宽；页面背景保留柔和颜色。
- 摄像头控制的横向映射更灵敏：不需要横跨很大幅度移动手臂就能换道。
- iPad Safari 地址栏属于浏览器界面，网页无法强制隐藏。若要减少 Safari 操作栏，可通过「分享」→「添加到主屏幕」再从图标启动。

## 历史记录与累计星星

- 捡到星星立即保存到当前浏览器的 localStorage，中途离开也保留已获得星星。
- 三颗爱心耗尽后记录一次完整游戏：日期、操控模式、所选难度、距离、当局星星；最近 80 局可浏览。
- 累计星星、完成游戏总局数、最高距离单独长期保存，不随重玩归零。
- 进入首页的「我的游戏记录」或结算页「查看历史记录」。
- 仅本机浏览器保存，换浏览器/换设备不互通；清理网站数据或无痕模式可能丢失。
- 升级前保存的最高分会自动保留；旧版并没有记录累计星星或历史局数，无法补算。

## 部署和维护

GitHub Pages 从仓库 `main` 分支根目录发布。根目录 `index.html` 内嵌 HTML、CSS、JavaScript，可直接部署，无构建和服务器需求。

手势依赖：MediaPipe Hands（Apache-2.0）。摄像头视频仅在当前设备进行姿态识别；应用不会上传视频。第三方 CDN 仅用于下载手势模型资源；国内网络可能无法稳定访问，后续可将模型资源自托管。
